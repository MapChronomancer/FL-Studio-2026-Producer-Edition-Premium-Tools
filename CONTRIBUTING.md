# Contributing to FL-Studio-2026-Producer-Edition-Premium-Tools

Thanks for taking the time to contribute!

## How to contribute

1. Fork the repository and create a topic branch.
2. Keep changes small and focused — one logical change per PR.
3. Run `pytest` before opening the PR.
4. Reference the related issue in the PR description.

## Reporting issues

Please include the runtime/toolchain version and a minimal reproduction.

## Code style

PEP 8. Line length soft-capped at 100.
